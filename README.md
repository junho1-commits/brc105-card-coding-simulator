## 🌟 주요 기능 및 핵심 특징

### 1. 🎴 BRC-105 실물 카드 디자인 완벽 재현 (43종 데이터베이스)
- 실물 카드의 비율, 둥근 모서리, 고유 카테고리 테두리 색상, 카드 번호(`#01`~`#43`), 직관적 그래픽 아이콘, 한글/영문 명칭 및 **하단 3색 실물 센서 코드 바 디테일**을 완벽하게 구현.
- **8개 카테고리 분류**:
  1. `시작 / 종료` (`#01` 코딩 시작, `#02` 코딩 끝)
  2. `이착륙 / 대기` (`#03` 이륙, `#04` 착륙, `#05`~`#07` 대기 1~3초)
  3. `평면 이동` (`#08`~`#19` 전진/후진/좌/우 1~3칸)
  4. `고도 제어` (`#20`~`#23` 상승/하강 1~2칸)
  5. `회전 제어` (`#24`~`#27` 좌/우 90도, 180도, 360도 제자리 회전)
  6. `특수 동작` (`#28`~`#31` 전진/후진/좌/우 360도 공중 플립)
  7. `제어 & 반복` (`#32`~`#35` 반복 시작 2~4회, 반복 끝)
  8. `LED & 소리` (`#36`~`#43` LED 색상 변경, 부저 1~2회)

### 2. 🧩 코딩 슬롯 작업 공간 (Block Assembly Workspace)
- 카드를 클릭하여 순서대로 배열, 삭제(`✖`), 순서 변경(`◀`, `▶`), 슬롯 전체 비우기.
- **필수 카드 안전 검증 규칙**: `[착륙]` 및 `[코딩 끝]` 카드가 빠져있으면 경고문과 함께 실행을 차단하여 학생들에게 안전한 코딩 습관 형성.
- **다양한 예시 코스 (6종)**: 사각 비행, 공중 플립, 반복 문법, 지그재그 순찰, 무지개 라이트쇼, 아크로바틱 콤보.

### 3. 🛰️ 듀얼 뷰 드론 비행 시뮬레이터 (Dual View Simulator)
- **위에서 본 장면 (Top View)**: 2D 그리드 지도, X/Y 좌표, 바라보는 방향(Heading), 비행 궤적(LED Glow Trail Line).
- **옆에서 본 장면 (Side View)**: 고도선(1m, 2m, 3m), 상승/하강, 이착륙, **360도 공중 플립 덤블링** 애니메이션 연출.
- **Web Audio API sound system**: 프로펠러 비행 엔진 소리, 부저 음, 플립 효과음, 축하 팡파르 sound.

### 4. 🎯 학생용 미션 도전 과제 & 🎓 가로형 수료 자격증
- **미션 모드 (6종)**: 목적지 타겟 착륙, 공중 플립, 무지개 LED, 반복 블록 효율왕, 360도 스핀, 최종 마스터 시험.
- **미션 성공 자동 판정**: 비행 완료 후 조건 자동 검증 및 축하 알림.
- **학생 이름 등록 & A4 가로 랜드스케이프 수료 자격증**:
  - 6개 미션 완수 시 학생 이름을 등록받아 공식 BRC-105 수료 자격증 발급.
  - 가로형 고급 금빛 테두리 & **한국 언플러그드 드론 교육협회장 직인 붉은 인장 도장 (Red Seal 💮)**.
  - **`[🖨️ 자격증 인쇄 / 다운로드]`** 버튼을 통해 A4 가로 상장 형태로 종이 인쇄 및 PDF 저장 지원.

### 5. 💻 크롬북(Chromebook) 최적화
- 학교 수업에서 많이 사용하는 크롬북 해상도(1366×768, 1280×720) 환경에서 8개 카테고리 탭과 카드가 잘리지 않고 한눈에 쏙 들어오도록 반응형 콤팩트 UI 적용.

## 🛠️ 실행 및 개발 방법

### 필수 조건
- [Node.js](https://nodejs.org/) v18 이상

### 설치 및 로컬 서버 가동
```bash
# 의존성 설치
npm install

# 개발 서버 실행 (Vite)
npm run dev
```
브라우저에서 `http://localhost:5173/` 접속하여 사용.

### 빌드 및 배포
```bash
# 프로덕션 빌드
npm run build
```
